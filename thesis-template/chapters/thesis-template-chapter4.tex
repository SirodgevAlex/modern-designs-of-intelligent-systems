\section{ТЕСТИРОВАНИЕ РЕЖИМА КОНСУЛЬТАЦИИ}

\subsection{Тестовый сценарий 1: Диагностика пероноспороза при высокой влажности}

При следующем начальном состоянии рабочей памяти:
\begin{itemize}
    \item Листья: желтовато-зеленые пятна угловатой формы (обнаружены за последние 2 дня)
    \item Нижняя сторона листьев: серовато-фиолетовый налет (обнаружен за последние 2 дня)
    \item Влажность воздуха: высокая (85\%)
    \item Влажность почвы: выше нормы (88\%)
    \item Содержание азота: неоптимальное (2.0\%)
\end{itemize}

Система выдает следующие диагнозы и рекомендации:
\begin{enumerate}
    \item Диагноз: ПЕРОНОСПОРОЗ (ложная мучнистая роса)
    \item Рекомендация: Обработать бордоской жидкостью в концентрации 1\%, прогреть семена при 45\textdegree{}C в течение 2 часов перед посевом на следующий сезон
    \item Рекомендация: Снизить влажность почвы путем уменьшения полива, проветрить посадки
    \item Рекомендация: Провести внесение азотных удобрений для стабилизации питания
    \item Состояние питания: НЕСТАБИЛЬНОЕ (требует внимания)
\end{enumerate}

Корректность диагноза: ПОДТВЕРЖДЕНА

Визуальные признаки полностью соответствуют симптоматике пероноспороза, система правильно идентифицировала заболевание на основе комбинации визуальных признаков и условий окружающей среды.

\subsection{Тестовый сценарий 2: Диагностика мучнистой росы}

При следующем начальном состоянии рабочей памяти:
\begin{itemize}
    \item Листья и стебли: белый мучнистый налет (обнаружен за последние 3 дня)
    \item Листья: закручивание, побурение (обнаружено за последние 2 дня)
    \item Влажность воздуха: высокая (78\%)
    \item Температура воздуха: умеренная (18\textdegree{}C)
    \item Влажность почвы: норма (75\%)
    \item Содержание калия: оптимальное (1.8\%)
\end{itemize}

Система выдает следующие диагнозы и рекомендации:
\begin{enumerate}
    \item Диагноз: МУЧНИСТАЯ РОСА
    \item Рекомендация: Обработать посадки коллоидной серой (100 г/10 л воды) два раза с интервалом 7-10 дней
    \item Рекомендация: Соблюдать севооборот, не высаживать на одном месте дыни более 2 лет подряд
    \item Рекомендация: Улучшить циркуляцию воздуха, удалить пораженные листья
    \item Состояние питания: СТАБИЛЬНОЕ
\end{enumerate}

Корректность диагноза: ПОДТВЕРЖДЕНА

Симптомы белого налета на листьях и стеблях с последующим закручиванием листьев являются классическими признаками мучнистой росы. Система корректно распознала заболевание и выдала адекватные рекомендации для лечения.

\subsection{Тестовый сценарий 3: Диагностика дефицита азота при нестабильном питании}

При следующем начальном состоянии рабочей памяти:
\begin{itemize}
    \item Нижние листья: бледно-зеленые (обнаружено за последние 3 дня)
    \item Содержание азота: критическое (1.0\%)
    \item Рост растения: замедленный (обнаружено за последние 4 дня)
    \item Влажность почвы: норма (72\%)
    \item Содержание фосфора: неоптимальное (0.4\%)
    \item Содержание калия: неоптимальное (1.2\%)
\end{itemize}

Система выдает следующие диагнозы и рекомендации:
\begin{enumerate}
    \item Диагноз: АЗОТНОЕ ГОЛОДАНИЕ
    \item Состояние питания: НЕСТАБИЛЬНОЕ (сочетание дефицитов NPK)
    \item Рекомендация: Внести азотные удобрения - мочевину (30-40 г/м\textsuperscript{2}) или аммиачную селитру (25-30 г/м\textsuperscript{2})
    \item Рекомендация: Провести листовую подкормку 2\% раствором нитрата кальция (20 г на 1 л воды) два раза с интервалом 5 дней
    \item Рекомендация: Дополнительно внести фосфорно-калийные удобрения для нормализации состояния
    \item Риск: Возможно развитие грибковых заболеваний при длительном дефиците питания
\end{enumerate}

Корректность диагноза: ПОДТВЕРЖДЕНА

Характерные признаки азотного голодания (побледнение нижних листьев, замедление роста) полностью совпали с признаками, описанными в базе знаний. Система также корректно определила нестабильное состояние питания, обнаружив сочетание дефицитов трех макроэлементов.

\subsection{Тестовый сценарий 4: Комплексная диагностика - множественные дефициты}

При следующем начальном состоянии рабочей памяти:
\begin{itemize}
    \item Между жилками старых листьев: хлороз (обнаружено за последние 2 дня)
    \item Между жилками молодых листьев: хлороз (обнаружено за последние 2 дня)
    \item Края листьев: буреют, краевой ожог (обнаружено за последние 2 дня)
    \item Содержание магния: неоптимальное (45 мг/кг)
    \item Содержание железа: критическое (5 мг/кг)
    \item Содержание калия: критическое (0.9\%)
    \item pH почвы: выше 7.5 (щелочная)
\end{itemize}

Система выдает следующие диагнозы и рекомендации:
\begin{enumerate}
    \item Диагноз: ДЕФИЦИТ МАГНИЯ
    \item Диагноз: ДЕФИЦИТ ЖЕЛЕЗА
    \item Диагноз: КАЛИЙНОЕ ГОЛОДАНИЕ
    \item Приоритет 1 - Рекомендация: Провести внекорневую подкормку сульфатом магния (15 г на 10 л воды) - опрыскивание нижней стороны листьев
    \item Приоритет 2 - Рекомендация: Провести внекорневую подкормку хелатом железа (10 г на 10 л воды), снизить pH почвы внесением серы или сульфата аммония
    \item Приоритет 3 - Рекомендация: Внести калийные удобрения (сульфат калия 30-40 г/м\textsuperscript{2}), избегать избыточного азотного питания
    \item Состояние питания: КРИТИЧЕСКОЕ С РИСКОМ ВЫМЫВАНИЯ
\end{enumerate}

Корректность диагноза: ПОДТВЕРЖДЕНА

Система успешно распознала три различных дефицита микроэлементов на основе различных визуальных признаков (хлороз между жилками в разных типах листьев, краевой ожог). Система также правильно определила щелочную среду как причину дефицита железа и выдала дифференцированные рекомендации по приоритетности действий.

\subsection{Тестовый сценарий 5: Диагностика фузариозного увядания}

При следующем начальном состоянии рабочей памяти:
\begin{itemize}
    \item Растение: увядает (обнаружено за последний день)
    \item Листья: желтеют от основания к верхушке (обнаружено за последние 2 дня)
    \item Корневая шейка: темнеет (обнаружено за последние 3 дня)
    \item Влажность почвы: высокая (82\%)
    \item Температура почвы: высокая (28\textdegree{}C)
    \item История: растение выращивается на том же месте второй год подряд
\end{itemize}

Система выдает следующие диагнозы и рекомендации:
\begin{enumerate}
    \item Диагноз: ФУЗАРИОЗНОЕ УВЯДАНИЕ
    \item Рекомендация: НЕМЕДЛЕННО удалить пораженные растения с корневой системой
    \item Рекомендация: Продезинфицировать почву раствором медного купороса (1\% раствор, 5-10 л/м\textsuperscript{2}) или формалином
    \item Рекомендация: ОБЯЗАТЕЛЬНО соблюдать севооборот - не выращивать дыни на этом месте минимум 4 года
    \item Рекомендация: Скорректировать режим полива - снизить влажность почвы до 65-70\%
    \item Критичность: МАКСИМАЛЬНАЯ - заболевание неизлечимо на поздних стадиях
\end{enumerate}

Результат действий системы: Поле было обследовано, пораженные растения удалены, почва продезинфицирована. На следующий год проведен посев бахчевых культур на соседнем участке. Урожай не пострадал.

Корректность диагноза: ПОДТВЕРЖДЕНА

Система правильно идентифицировала наиболее опасное заболевание на основе характерного симптомокомплекса (увядание листьев, потемнение корневой шейки). Система выдала критически важные рекомендации о необходимости удаления растений и соблюдении севооборота.

\section{ТЕСТИРОВАНИЕ РЕЖИМА ИМИТАЦИИ}

\subsection{Эксперимент 1: Моделирование нестабильного содержания азота при различных уровнях осадков}

Начальные условия:
\begin{itemize}
    \item Время эксперимента: 15 дней
    \item Содержание азота (начальное): 2.2\% (оптимальное)
    \item Режим осадков: переменный (день 1-3: низкие 0.5 мм, день 4-7: высокие 4.5 мм, день 8-15: средние 2.0 мм)
    \item Влажность почвы (начальная): 72\%
    \item Другие показатели: в норме
\end{itemize}

Динамика показателей во времени:

День 1-3 (низкие осадки):
\begin{itemize}
    \item Содержание азота: 2.2\% \textrightarrow{} 2.0\% (начало снижения из-за отсутствия пополнения)
    \item Влажность почвы: 72\% \textrightarrow{} 65\%
    \item Диагноз: оптимальное состояние питания
\end{itemize}

День 4-7 (высокие осадки):
\begin{itemize}
    \item Содержание азота: 2.0\% \textrightarrow{} 1.5\% (резкое снижение из-за вымывания)
    \item Влажность почвы: 65\% \textrightarrow{} 80\%
    \item Визуальные симптомы: начинает появляться побледнение нижних листьев
    \item Диагноз: состояние питания НЕСТАБИЛЬНОЕ, риск вымывания
\end{itemize}

День 8-15 (средние осадки):
\begin{itemize}
    \item Содержание азота: 1.5\% \textrightarrow{} 1.2\% (продолжение снижения)
    \item Влажность почвы: 80\% \textrightarrow{} 73\%
    \item Визуальные симптомы: выраженное побледнение нижних листьев, замедление роста
    \item Диагноз: АЗОТНОЕ ГОЛОДАНИЕ, состояние КРИТИЧЕСКОЕ
\end{itemize}

Рекомендации системы:
\begin{enumerate}
    \item День 5: Снизить полив до 2-3 мм/день
    \item День 7: Внести азотные удобрения немедленно
    \item День 10: Провести листовую подкормку нитратом кальция
    \item День 12: Проверить pH почвы и при необходимости отрегулировать
\end{enumerate}

Результат эксперимента: УСПЕШНО

Система корректно смоделировала процесс вымывания азота при избыточных осадках и правильно определила динамику развития дефицита. Рекомендации выдавались своевременно.

\subsection{Эксперимент 2: Моделирование одновременного дефицита NPK и развития грибковых заболеваний}

Начальные условия:
\begin{itemize}
    \item Время эксперимента: 20 дней
    \item Макроэлементы (начальные): N 1.8\%, P 0.4\%, K 1.1\% (неоптимальные)
    \item Влажность воздуха (начальная): 70\%
    \item Температура воздуха (начальная): 20\textdegree{}C
    \item День 8-15: влажность воздуха повышается до 85\%, температура 18\textdegree{}C
\end{itemize}

Динамика показателей во времени:

День 1-7 (начальный период дефицита):
\begin{itemize}
    \item N, P, K: медленное снижение без внешних воздействий
    \item Визуальные симптомы: листья приобретают слегка темную окраску, краевой ожог
    \item Диагноз: состояние питания НЕСТАБИЛЬНОЕ
\end{itemize}

День 8-12 (условия благоприятны для грибков):
\begin{itemize}
    \item Влажность воздуха поднялась до 85\%
    \item Температура оптимальна (18\textdegree{}C)
    \item На листьях появляются белые мучнистые налеты
    \item Диагноз: МУЧНИСТАЯ РОСА + НЕСТАБИЛЬНОЕ ПИТАНИЕ (комплексная проблема)
\end{itemize}

День 13-20 (развитие заболевания):
\begin{itemize}
    \item Мучнистая роса распространяется на 30-40\% листовой поверхности
    \item Питательное состояние дополнительно ухудшается
    \item Темпы роста замедляются на 50\%
    \item Диагноз: КРИТИЧЕСКОЕ СОСТОЯНИЕ поля
\end{itemize}

Система выдала рекомендации:
\begin{enumerate}
    \item День 8: Немедленно начать обработку коллоидной серой
    \item День 9: Снизить влажность воздуха путем проветривания
    \item День 10: Внести азотные и калийные удобрения
    \item День 12: Повторная обработка фунгицидом
    \item День 15: Проверка эффективности лечения
\end{enumerate}

Результат эксперимента: УСПЕШНО

Система правильно смоделировала влияние комбинированного дефицита питания и грибкового заболевания. Была выявлена синергия между этими факторами - дефицит питания снижает устойчивость растений к болезням.

\subsection{Эксперимент 3: Моделирование благоприятных условий для развития антракноза}

Начальные условия:
\begin{itemize}
    \item Время эксперимента: 18 дней
    \item Температура воздуха: 24-25\textdegree{}C (высокая)
    \item Влажность воздуха: 65\% \textrightarrow{} 75\% (период повышения)
    \item Влажность почвы: 70\%
    \item pH почвы: 6.5 (нейтральная)
    \item Питание растений: оптимальное
\end{itemize}

Динамика показателей во времени:

День 1-5 (оптимальные условия роста):
\begin{itemize}
    \item Все показатели в норме
    \item Растения активно развиваются
    \item Визуальные симптомы: отсутствуют
    \item Диагноз: состояние СТАБИЛЬНОЕ
\end{itemize}

День 6-12 (повышение влажности, сохранение высокой температуры):
\begin{itemize}
    \item Влажность воздуха: 65\% \textrightarrow{} 75\%
    \item Температура: стабильно 24\textdegree{}C
    \item На листьях начинают появляться желтые и коричневые пятна с темной каемкой
    \item Пятна локализуются в основном на нижней части листа
    \item Диагноз: АНТРАКНОЗ (ранняя стадия)
\end{itemize}

День 13-18 (прогрессирование болезни):
\begin{itemize}
    \item Пятна антракноза распространяются быстро
    \item На стеблях появляются вдавленные овальные язвочки
    \item Болезнь поражает до 50-60\% листовой поверхности
    \item Начинается засыхание листьев
    \item Диагноз: АНТРАКНОЗ (активная стадия)
\end{itemize}

Система выдала рекомендации:
\begin{enumerate}
    \item День 7: Обнаружен риск развития грибковых болезней
    \item День 8: Удалить пораженные части растений (первые пятна)
    \item День 9: Начать обработку фунгицидами (медьсодержащие препараты)
    \item День 11: Повторная обработка фунгицидом
    \item День 14: Проветривание, снижение влажности
    \item День 16: Применение системных фунгицидов при необходимости
\end{enumerate}

Результат эксперимента: УСПЕШНО

Система правильно предсказала развитие антракноза при сочетании высокой температуры и повышенной влажности. Своевременные рекомендации по обработке позволили остановить распространение болезни на стадии до 70\% поражения листьев.

\subsection{Эксперимент 4: Моделирование влияния загрязнений на изменение pH почвы и развитие дефицита железа}

Начальные условия:
\begin{itemize}
    \item Время эксперимента: 25 дней
    \item pH почвы (начальный): 6.8 (нейтральная)
    \item Содержание железа: 8 мг/кг (оптимальное)
    \item Выбросы загрязнений (начиная с дня 5): 500 л/сут щелочных веществ
    \item Другие показатели: в норме
\end{itemize}

Динамика показателей во времени:

День 1-5 (нормальное состояние):
\begin{itemize}
    \item pH почвы: 6.8
    \item Содержание железа: 8 мг/кг
    \item Растения развиваются нормально
    \item Диагноз: состояние СТАБИЛЬНОЕ
\end{itemize}

День 6-12 (начало загрязнения):
\begin{itemize}
    \item Поступление щелочных выбросов: 500 л/сут
    \item pH почвы: 6.8 \textrightarrow{} 7.0 \textrightarrow{} 7.3
    \item Содержание железа: начинает снижаться из-за связывания в щелочной среде
    \item Визуальные симптомы: между жилками молодых листьев появляется светлая окраска
    \item Диагноз: ранние признаки ДЕФИЦИТА ЖЕЛЕЗА
\end{itemize}

День 13-20 (прогрессирование ацидификации):
\begin{itemize}
    \item pH почвы: 7.3 \textrightarrow{} 7.6 \textrightarrow{} 7.8 (щелочная среда)
    \item Содержание железа: снизилось до 3 мг/кг (критическое)
    \item Хлороз листьев становится более выраженным
    \item Развивается межжилковый хлороз молодых листьев
    \item Диагноз: ДЕФИЦИТ ЖЕЛЕЗА (активная стадия)
\end{itemize}

День 21-25 (критическое состояние):
\begin{itemize}
    \item pH почвы: 7.8 (сильно щелочная)
    \item Содержание железа: 1.5 мг/кг (критическое)
    \item Хлороз покрывает 40-50\% листовой поверхности молодых листьев
    \item Замедление роста, ослабление растений
    \item Диагноз: КРИТИЧЕСКОЕ СОСТОЯНИЕ
\end{itemize}

Система выдала рекомендации:
